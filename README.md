# Day-16-of-Learning-Java
In the day 16 I have learn about the Java Collection Framework-Collection Hierarchy and made program based on { Modifying Array List ,Custom Book object by overridden toString() method , Performing Linked List Operations , sortStudents by LinkedList, 8 streams &amp; Lambda Expressions}.

The problems are as following:-

Q1. Demonstrate a java program with the classname ModifyArrayList,Use ArrayList package and store fruits- [Apple,banana,orange]. Remove the elements banana, update the 1st 
    element to Cherry And print the list.
    
Q2. Demonstrate a java program named ArrayListWithBooks that uses an ArrayList to store custom Book objects.The Book class should have title ,author and year as attributes,a 
    constructor to initialize them, and an overridden toString() method to display book details.Add a few books details to the list and print the list.
    
Q3. Demonstrate a java program named LinkedListOperations.Use the LinkedList packages and make one object fruits. Initially add two fruits on start and end - "Mango","Orange"
    Then make one regular add - "Banana","Cherry",Remove elements by value,first and last And then print the final list.
    
Q4. Write a java program named sortStudents that defines a class Student with attributes name(String), and marks(int).Create a LinkedList of Student objects,and demonstrate 
    how to sort the list in decending order based on marks using java's Comparator.Display the sorted list using a loop.
    
Q5.Write a Java program using java 8 streams and Lambda Expressions to process a list of names.
   i. Create a list of names using Arrays.asList().
   ii. Using Streams and Lambda Expressions to perform the following operations-
        Filter the names startwith() the letter "R"
        Convert the filter names to uppercase.
        Collect the result into a new list.
   iii. Print the final list of names.
